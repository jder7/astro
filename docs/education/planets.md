## Purpose

Planets are the **active operators** of a chart:
- **Signs** describe *how* energy behaves (style, tone, “movement pattern”).
- **Houses** describe *where* it plays out (life arenas).
- **Planets** describe *what function* is doing the acting (drive, meaning-making, bonding, discipline, awakening, etc.).

In an **esoteric** frame, a planet is also a **carrier of ray energy** — a vibrational “quality stream” that can express as:
- a *reactive habit* (personality),
- a *conscious value* (soul-aligned),
- or a *collective power* (hierarchic).

<a id="how-to-use-planets"></a>
## How to use planets

### Natal (baseline wiring)
Read each planet through:
1) **Planet** = what function is operating  
2) **Sign** = how it tries to operate  
3) **House** = where it’s most visible / tested  
4) **Aspects** = who is collaborating with (integration work)

### Transits (timing + activation)
- Transiting planets **activate** natal functions by aspect or by moving through sensitive houses/signs.
- Slow transits (♄, ♅, ♆, ♇) reshape the *operating system*; fast ones (☾, ☿, ♀, ♂) trigger *events and responses*.

### Synastry (two systems meeting)
- Person A’s planet aspecting Person B’s planet = “how my function touches your function.”
- Person A’s planets hitting Person B’s **rulers** (house rulers / sign rulers) creates especially strong handles.

<a id="the-developmental-octave-lens"></a>
## The developmental octave lens

Use this as a **map of expression levels**, not a label.

- **Exoteric octave (outer, personality)**  
  The planet expresses as *reaction and self-protection*: desires, defenses, strategy, survival logic.

- **Esoteric octave (inner, soul-aligned)**  
  The same function becomes *value-led*: conscience, meaning, right relation, constructive creativity.

- **Hierarchic octave (collective)**  
  The function becomes *stewardship*: responsibility for the collective, building for the whole, “white-magic” level application.

<a id="veils-and-substitutions"></a>
### Veils and substitutions

**☉ Sun** and **☾ Moon** are treated as *symbolic veils* that can hide/reveal other planetary energies.

**Common “Moon veils” used in the rulership model**
- ☾ **Moon → Vulcan** (etheric/physical correction, discipline of embodiment)
- ☾ **Moon → Neptune** (emotional purification, collective sensitivity)
- ☾ **Moon → Uranus** (mental liberation, group mind transformation)

**How to use this in practice**
- If a chart is Moon-heavy: ask *“Is this pure lunar habit or is a veiled planet trying to express?”*
- The “veil” often shows up as: *the person can’t name the higher impulse yet*, but life keeps training it.

## How planets interact

Think of aspects as **energy conversations** between functions.

<a id="aspect-dynamics-fast-decoding"></a>
### Aspect dynamics (fast decoding)

- **Conjunction (0°):** fusion — amplified, inseparable learning.
- **Opposition (180°):** polarity — projection → integration through relationship.
- **Square (90°):** friction — skill-building under pressure; the “engine aspect.”
- **Trine (120°):** easy flow — talent, comfort; growth requires *choice*.
- **Sextile (60°):** opportunity — latent synergy; requires activation.

<a id="ray-resonance-vibration-compatibility"></a>
### Ray resonance (vibration compatibility)

- **Same ray tone** → recognition, fast resonance (easy to coordinate).
- **Complementary rays** → productive synthesis (e.g., <span style="color:#6366f1">Ray 2</span> meaning + <span style="color:#fb923c">Ray 5</span> precision).
- **Clashing tempo** → translation work (e.g., <span style="color:#a78bfa">Ray 7</span> structural change vs <span style="color:#22d3ee">Ray 6</span> devotional drift).

Use this to explain why two people can have “compatible signs” but still clash: their **planetary rays** aren’t speaking the same language.

### Functional pairs (psychological synthesis)

- **☿ Mercury + ♀ Venus** → thinking + valuing = taste, diplomacy, “intelligent love”
- **♂ Mars + ♄ Saturn** → drive + structure = mastery (or frustration if the motive is dirty)
- **♃ Jupiter + ♄ Saturn** → meaning + limits = mature success (growth that lasts)
- **♅ Uranus + ♆ Neptune** → awakening + dissolution = mystic innovation (or confusion without grounding)
- **♇ Pluto + ☉ Sun** → identity + transformation = rebirth of purpose (or power struggle if resisted)
